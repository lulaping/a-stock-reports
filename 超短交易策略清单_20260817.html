超短交易策略清单

可执行的每日复盘 + 选股 + 执行 + 退出 SOP · 2026-08-17 编制

核心原则：情绪周期定仓位，竞价信号定买卖，板块成建制定方向，断板次日必止损。

定性判断（每项必答）：

  • 今天是趋势日还是连板日？（趋势日 = 指数放量+抱团核心；连板日 = 梯队完整+晋级率高）→ 明日策略：趋势日→低吸核心；连板日→打板接力
  • 当前最强主线板块：____（板块内≥3只涨停才算成建制）
  • 今日弱转强标的：____（昨日烂板/分歧，今日竞价低开但分时拉红封板）→ 明日重点观察
  • 今日异动公告数量：____ 只 → 若≥3只，次日退潮概率高，降仓
  • 明日情绪温度预估：____°C → 参考仓位：<50°C ≤3成 / 50-90°C 5成 / 90-120°C 7成 / >120°C 5成（高潮降仓）

清单2：晚间选股（20:00 — 筛选次日候选）

步骤：

  1. 拉今日涨停池 → 排除 ST / 一字板无换手 / 尾盘偷袭(14:30后) / 流通市值>200亿
  2. 分类标注 三档：
    S级 弱转强+板块成建制+产业资本催化（至少满足2项）
    A级 板块成建制+封板质量高，但无产业催化
    B级 独苗涨停/玄学炒作/跟风补涨
  3. 淘汰 以下任一情形：
    • 大股东质押>50% 或 商誉/净资产>50%
    • 公司已发澄清公告/异动公告
    • 龙虎榜全为"一日游"游资
    • 同板块最高标今日断板
  4. 筛选结果：S级 ____ 只 / A级 ____ 只 / B级 ____ 只

清单3：竞价阶段（9:15-9:25 — 10分钟决生死）

检查项通过标准不通过则
高开幅度一进二 2-5%；高标 1-3%＞7%高开 → 放弃（兑现盘砸盘）；低开＞3% → 放弃
竞价量比竞价成交/昨日成交 5-15%＜3%（无承接）→ 放弃；＞25%（分歧巨大）→ 观望
竞价形态低开→9:25竞价拉高（分歧转一致）高开→9:20后持续撤单 → 放弃
20cm票9:20-9:25封单递增大幅低开 → 放弃
板块确认同板块至少2只竞价高开确认独苗高开 → 降半仓
核心信号 —— 弱转强：昨日炸板/烂板，今日竞价低开但分时快速拉红。这是2026年胜率最高的买入形态，资金自救+抢筹共振。
竞价阶段直接淘汰：一字板不给机会的 → 不追（开板即分歧，追入即接盘）；大盘竞价低开且翻绿 → 所有买入计划推迟30分钟。

清单4：盘中执行（9:30-15:00 — 按纪律执行）

时间窗口动作纪律
9:30-9:35观察弱转强标的能否拉红竞价低开但5分钟内拉红 → 可半仓试；5分钟未拉红 → 放弃
9:35-10:00确认封板质量封单/成交比＞3x → 可加仓；开板≥3次 → 减仓
10:00-10:30早盘封板可追10:30前封板 → 质量好；午后封板 → 只低吸不追高
14:30后尾盘偷袭不碰14:30后才封板 → 一律不参与，次日溢价极低
全天监控同板块高标同板块最高标断板 → 立即减仓，板块退潮信号
全天监控异动公告持仓股盘中发公告 → 立即清仓，无例外

清单5：退出纪律（无例外）

  • 铁律1：断板次日必须止损。不管任何理由，昨日涨停今日未封板 → 开盘即卖。反包是重新上车的机会，不是硬扛的理由。
  • 铁律2：同梯队2只以上同时断板 → 全清。这是主线退潮的明确信号，不分个股强弱。
  • 铁律3：单票亏损＞-5% → 无条件止损。不补仓、不扛单、不等反包。
  • 铁律4：大盘跳水翻绿 → 减仓至3成。系统性风险面前不分个股。

清单6：仓位管理

情绪温度仓位上限单票上限单日交易上限
＜50°C（冰点）3成1成≤2只
50-90°C（温和）5成1.5成≤3只
90-120°C（活跃）7成2成≤3只

高潮期特殊规则：＞120°C 只做核心不追高标，预留至少3成现金应对次日分歧。高潮次日往往是亏钱效应最大的交易日。

清单7：三类高胜率模式快速识别卡

模式识别条件买入时机退出条件
① 弱转强反包 昨日烂板/炸板/分歧 + 今日竞价低开→分时拉红 分时拉红确认后 半仓；封板加仓 次日不封板即走；炸板走
② 板块成建制 板块≥3只涨停 + 高标带队 + 处在加速期 竞价确认板块高开 + 个股过竞价清单 板块高标断板 → 全清
③ 产业资本催化 股权转让/大基金入股/定点中标公告 公告后首板打板/次日竞价确认 公告利好兑现（2-3板后）→ 分批止盈
